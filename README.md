# Портфолио системного аналитика

Учебный проект: сбор и оформление требований к информационно-образовательной среде (ИОС) вуза.
Роль: системный аналитик (в команде из 5 человек).

## О проекте

Информационно-образовательная среда для вуза: обмен материалами между студентами и преподавателями, учебные планы, форумы дисциплин, рассылки.
Цель — соответствие требованиям ФГОС для прохождения аккредитации.

## Что сделано

- Интервью с заказчиком и первичные требования
- Протокол собеседования
- Функциональные требования + глоссарий
- Use Cases (11 сценариев)
- Диаграммы последовательности (9 шт.)

## Структура

| Папка | Что внутри |
|---|---|
| `01-requirements` | Функциональные и нефункциональные требования |
| `02-use-cases` | Сценарии использования |
| `03-diagrams` | Диаграммы последовательности |
| `04-protocol` | Протокол интервью с заказчиком |
| `05-glossary` | Глоссарий терминов |

## Инструменты

- **draw.io** — диаграммы
- **Markdown** — документация

## Чему я научилась

- Проводить интервью с заказчиком и выявлять неявные требования
- Формулировать требования, проверяемые и однозначные
- Строить диаграммы последовательности
- Оформлять аналитическую документацию в Markdown
- Работать с конфликтами в требованиях (например, «доступ ко всем дисциплинам» vs «редактировать только свои»)
