# Функциональные требования 

## Название и цель системы

Разрабатываемая Информационно-образовательная среда (ИОС) предназначена
для успешного прохождения процедуры аккредитации вуза. Целью системы
является соответствие требованиям к информационно-образовательной среде,
указанным в Федеральном государственном образовательном стандарте[^1]
(ФГОС).

> Ключевые требования включают:

- доступ к учебным планам, рабочим программам дисциплин (модулей),
  практик, электронным учебным изданиям и электронным образовательным
  ресурсам, указанным в рабочих программах дисциплин (модулей), практик;

- взаимодействие между участниками образовательного процесса, в том
  числе синхронное и (или) асинхронное взаимодействия посредством сети
  \"Интернет\".

## Тип продукта и группы пользователей

ИОС должна быть реализована в виде WEB-портала в сети «Интернет». ИОС
должна предоставлять функционал для авторизированных пользователей
(Студент, Преподаватель, Администратор, Менеджер) и ограниченный
функционал для группы «Гость».

## Общие функции

### Главная страница

На главной странице будет размещена основная информация, в которую
входит список институтов, у каждого института список направлений, каждое
направление только в одном институте, у каждого направления есть ссылка
на учебный план этого направления.

У каждого пользователя будут отображаться приветствие (для
зарегистрированных в виде "Здравствуй, Иван и те личные данные, которые
свойственны разным категориям пользователей.

Также у всех пользователей набор кнопок (или меню), которые будут
отображать все его функциональные возможности.

На главной странице будет размещена контактная информация в виде
телефона администратора, его email, а для авторизированных еще
дополнительная функция обращения в техподдержку.

### Авторизация

При авторизации у пользователя будет запрашиваться логин и пароль. Если
пользователь забыл пароль, то восстановление будет проходить через
администратора. Если пользователь три раза подряд неправильно ввел
пароль, то система блокируется на 20 минут. При первом входе в аккаунт
пользователю будет предложено изменить пароль на собственный. Если
пользователь воспользовался функцией "Запомнить меня", то его логин
запоминается и при дальнейших посещениях ИОС будет запрашиваться только
пароль.

###  Отправка сообщений в рассылке

Пользователь может отправить сообщение, указав логин получателя, и оно
будет доставлено на электронную почту, привязанную к его аккаунту. Если
пользователь - Студент, то он может отправлять сообщения всем
преподавателям, которые закреплены за дисциплиной его направления;
Преподаватель может отправлять сообщения всем Студентам, которые в
данном семестре изучают дисциплину, за которую он закреплён, в том числе
и целой группе сразу;

Менеджер может осуществлять рассылку на всех преподавателей своего
института;

Администратор может осуществлять рассылку либо всем пользователям сразу,
либо группе пользователей, либо выбирать пользователей по фамилиям.

###  Отправка сообщений в форуме 

Эта функция доступна только пользователям с ролью Студент и
Преподаватель, прикрепленные к этой дисциплине.

Пользователь может оставлять сообщение в форуме. Сообщение может быть
только текстовым. Количество символов не ограничено.

### Просмотр учебного плана 

Эта функция доступна только для всех пользователей

Пользователю будет отображаться Учебный план (смотри в глоссарий), без
возможности сортировки и фильтрации.

### Просмотр материалов дисциплины

Пользователю будут отображаться Материалы дисциплины (файлы в формате
word pdf и рисунки любые) без возможности скачивания, сортировки или
фильтрации. Если пользователь является Студентом, то ему доступно
скачивание файлов.

## Функции Администратора

### Регистрация пользователей

В системе предполагается регистрация разных групп пользователей. Для
регистрации отдельного студента, преподавателя и администратора будет
использоваться ручной ввод с такими общими данными, как ФИО и email.

При ручном вводе для регистрации отдельного студента будут учитываться
общие данные, направление, на котором он учится, курс (1-4), номер
зачетки (8 уникальных цифр). Все данные обязательны, кроме отчества.

Для регистрации преподавателя будет использоваться общие данные,
кафедра, должность (ассистент, доцент, профессор, заведующий кафедрой).

Учетная запись первого администратора будет внесена при разработке. Для
регистрации администратора нужны только общие данные.

Для регистрации группы студентов первого курса будет использоваться ввод
файла. Формат файла Excel, в нем размещены три столбца: в первых двух
общая информация, в третьем номер зачетки. В названии файла написано
направление. На каждый курс и направление отдельный файл со списком
данных студентов.

В качестве логина будет фамилия и инициалы пользователя, которые будут
генерироваться автоматически латинскими буквами. Если генерируется
логин, который уже есть в системе, тогда администратору будет предложено
ввести логин вручную и как-то его изменить.

Пароль также будет генерироваться. Пароль и логин при генерации
отправляется на указанную почту.

Для регистрации менеджера нужны общие данные и наименование института.

### Изменение и удаление данных о пользователях

Администратор может изменять и удалять данные о пользователях, введённые
при регистрации.

### Управление институтами 

Администратор может создавать новый институт в системе.Для создания
института требуется указать название института и логин
зарегистрированного Менеджера. В дальнейшем этот Менеджер будет
считаться закрепленным за данным институтом.

## Функции Преподавателя

### Изменение материалов дисциплины

Преподаватель может создавать и изменять материалы дисциплин, за
которыми он закреплен. Для каждой дисциплины Преподаватель может
создавать любое количество папок и может выкладывать туда любые файлы в
формате Word, PDF и любой формат рисунков. Редактировать форум и раздел
"Часто задаваемые вопросы" Преподаватель может только для тех дисциплин,
за которыми он закреплен.

### Мои курсы

У преподавателя есть кнопка "мои курсы", в нем имеется перечень
дисциплин, за которыми он закреплен, отсортированных в алфавитном
порядке, [но пользователь может изменить порядок.]{.mark} [Этот список
является интерактивным: преподаватель может сортировать его по различным
параметрам, фильтровать по названию или семестру (по числам).]{.mark}

###  Редактирование форума

У Преподавателя есть возможность удалять сообщения в форуме, а также
добавлять, редактировать и удалять вопросы и ответы в разделе "Часто
задаваемые вопросы" для доступной дисциплины.

## Функции Менеджера

### Управление учебным планом 

Менеджер института создает направления и формирует для них учебный план.
Их формирование осуществляется путем загрузки файлов в формате Excel.

Строки с некорректными данными не создаются, и система фиксирует их
исключение. Если указан преподаватель, отсутствующий в системе,
дисциплина создается, но без указания преподавателя, а менеджер получает
соответствующее предупреждение. При обнаружении в системе нескольких
преподавателей с одинаковой фамилией менеджеру предоставляться выбор для
нужного пользователя из списка. Менеджер может вручную добавить нового
преподавателя в систему.

Менеджер института может вносить изменения в соответствующий учебный
план.

Менеджер института может удалять данные из соответствующего учебного
плана.

###  Управление направлениями и кафедрами института

Менеджер может изменять, удалять, создавать направления и кафедры
института.

## Функции Времени

30 августа каждого года автоматически будет происходить перевод Студента
на следующий курс, Архивирование даннных о пользователях и Очистка
форума.
